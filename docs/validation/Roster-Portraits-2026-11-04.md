Source inspection found an unbounded serialized profile wait, canceled task Result access outside error handling, synchronous fetch errors outside the per-entry catch, and pending native icon callbacks with no roster-owned disposal. A failed iterator could also leave the shared coroutine handle non-null, preventing later work from starting.
