# Core proposals

Current behavior is indexed in [Core documentation](README.md). Release-test qualification is tracked in [the current test checklist](validation/Release-Test-2026-11-05.md). These proposals are not release commitments.

- Player-Scav recruitment of other Scavs using Fence-standing admission and return of handed-over gear after extraction. Existing PMC-player Allegiance Scav companions do not implement this proposal.
- Squad Budget/Command Points and additional looting features need separate design and authorization.

The implemented Going Rogue extension is documented in its [addon guide](../going-rogue/README.md). SAIN addon proposals remain in its [own roadmap](../addon/docs/Roadmap.md).
